# Glosario de la interfaz

Este glosario fija los términos visibles de CryptoCarver y evita mezclar
idiomas. Los nombres de estándares, algoritmos y formatos se conservan tal
como aparecen en su documentación técnica.

| Inglés técnico | Etiqueta en español | Criterio |
|---|---|---|
| History | Histórico | Todas las ejecuciones persistidas. |
| Session log | Registro de sesión | Pasos que el usuario decide guardar para un informe. |
| Clipboard Shelf | Estante del portapapeles | Colección temporal de valores copiados entre herramientas. |
| Inspector | Inspector | Panel de detalles de la operación activa. |
| Quick Start | Inicio rápido | Panel inicial con accesos guiados. |
| Key Check Value (KCV) | Key Check Value (KCV) | Término técnico de criptografía; se conserva. |
| HMAC, CMAC, AES, TR-31, PKCS#11, JOSE, COSE | Sin traducir | Nombres propios de algoritmos, estándares o formatos. |
| Experimental | Experimental | Estado de una operación disponible pero aún en evaluación. |
| Planned | Planificada | Operación catalogada pero no disponible para ejecutar. |

Los datos técnicos (claves, bytes, PEM, JSON/XML, identificadores, nombres de
algoritmo y valores de histórico) no se traducen ni se transforman.
