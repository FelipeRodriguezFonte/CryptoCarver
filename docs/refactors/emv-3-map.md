The phase is not separable as a single ARPC coordinator: `clearModuleData` resets every EMV tab and ARQC verification cache, while `loadProfile` restores EMV fields/status. Put these separate module lifecycle operations in `EmvModuleStateCoordinator`, and only the ARPC action in `EmvArpcCoordinator`. Both use records of lazy control suppliers and `Supplier<StatusReporter>`; no coordinator stores a controller. The public FXML/controller entry points remain one-line delegates and public API signatures do not change. `deriveLaboratorySessionKey` is a stateless helper and may become package-private static for the state coordinator to reuse without capturing an `EmvSessionKeyCoordinator` or controller.
